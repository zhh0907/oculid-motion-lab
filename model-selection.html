Two movement models

The simulator defaults to the expanded-data GRU. The long-training GRU remains as a comparison. Older GRU variants, MLP, LSTM and rule controllers are no longer loaded or offered in the app. Historical evaluation files remain in the repository.

The expanded model also reduced 20 ms velocity error on both binocular domains (10.863 → 10.627°/s and 10.715 → 10.496°/s). The checkpoints were selected by validation performance. The prior test set has been reused; these findings remain exploratory. Other sessions contain the same held-out people. The external right-eye test has only three people and did not improve every metric.

Reference modes

Geometric reference points directly toward the target and helps inspect the patient layer without learned movement dynamics. It is not a learned model or a claim of realistic human movement. Recorded gaze is available only in dataset replay.

Changing the model

Open Advanced settings (on mobile: Patient & settings → More). A model change restarts the current run but keeps the patient's saved parameters. Exact reproduction requires the same controller/input sequence and initial state; a patient ID alone does not fix the normal controller.

Patient layer

Both models and the references feed the same fixed-patient layer. Its capacity ranges have not been clinically validated, and the simulator assigns no NIHSS score. Patient workflow and mathematics.
