# 0.6：扫描面部与动态眼睑

本次外观更新使用 Lee Perry-Smith 的 **Infinite, 3D Head Scan**，替换原先接近平面的程序化眼周背景。鼻梁、鼻翼、鼻底、面颊、耳部和头部轮廓来自实际扫描网格；眉毛和肤色细节来自其原始颜色贴图。眼球、眼裂、眨眼及病例运动仍由本项目实时计算。

## 素材、许可和修改

- 作者：Lee Perry-Smith；原作品基于 [Triplegangers](https://www.triplegangers.com/)。
- 分发来源：[Three.js r180 / LeePerrySmith](https://github.com/mrdoob/three.js/tree/r180/examples/models/gltf/LeePerrySmith)。
- 素材许可：[Creative Commons Attribution 3.0](https://creativecommons.org/licenses/by/3.0/)。原许可文件见 `vendor/face/LeePerrySmith_License.txt`；来源、SHA256 和修改说明见 `vendor/face/PROVENANCE.json`。
- 原 GLB 和颜色贴图原样保留。运行时缩放、对齐扫描网格，去掉眼周内部三角形，再接入可运动的眼睑。肤色调整及原扫描闭眼线的局部融合由着色器完成。
- 扫描素材只用于虚拟外观。模拟病例及其运动限制与被扫描者无关，也不代表作者认可本项目。

## 几何连接

扫描两侧眼角的中点对齐到既有眼球中心间距 **64 mm**。统一缩放使用：

`scale = 0.064 / (rightAnchor.x - leftAnchor.x)`

随后将坐标平移到两眼中点，并把眼角附近的深度放在眼球前方。这里的锚点来自扫描模型正面渲染上的定位和射线回投；它是工程配准，不是临床测量结果。

静态面部直接使用原扫描三角网格，保留鼻底和耳部的三维结构。动态眼周需要查询任意 `(x,y)` 对应的皮肤深度和纹理坐标，因此离线将扫描正面投影成 241 × 361 的深度 / UV 场。深度采用三次插值，UV 采用双线性插值，眼睑外缘与该场连接，内缘继续遵循原有眼球接触和闭合约束。面部左右自然存在深度差异；水平运动约定与二维眼裂仍保持原来的镜像关系。

构建脚本：`scripts/build-face-scan.py`，依赖 NumPy / SciPy。网页直接读取已生成的数据，不运行 Python。原扫描跨越眼周边界的三角形保留在动态眼周之下，避免按三角形中心裁切留下孔洞。

## 显示和操作

- 正面长焦透视视图，扩大到同时看见鼻部和面颊；柔化侧上方照明，保留鼻部和眼眶的体积感。
- 皮肤保留细微表面起伏、粗糙度和柔和高光，避免均匀塑料材质。
- 肤色改成浅、自然、中等、棕、深五种预设；虹膜保留棕、榛绿、蓝灰三种。取消所有自由调色盘。
- 改肤色仍按原界面行为开启新记录，但不会重新随机患者参数。患者编号、模板、侧别、手指跟随、实时滑轴和轨迹图继续使用既有运动流程。

## 验证与边界

36 个 Node 测试检查原模型输出一致性、固定患者复现、眼睑闭合 / 接触约束、扫描素材哈希和深度 / UV 的有效性。浏览器检查涵盖五种肤色、固定患者保持、单眼受限、左右及上下极限注视、闭眼、手机宽度以及原有患者库 / 曲线 / 导出功能。检查结果见 `docs/face-report.json` 和 `docs/browser-report.json`。

该外观更接近真人，但仍是**一个参考身份上的实时合成脸**，没有实现多身份人脸生成、组织级光学散射或扫描级动态眼睑。颜色贴图包含原始采集时的色调和部分光照信息；五种肤色是视觉预设，不是经标定的人群皮肤分布。当前瞳孔可见比例和滑轴依旧使用原有几何近似，并非从新透视画面重新做图像追踪。临床评分有效性不由外观测试证明。
