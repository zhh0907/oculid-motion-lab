# 0.3：连续眼角与皮肤细节

更新：2026-10-27。

旧版眼角使用独立椭球，正面看起来像珠子，侧看时也没有真正连接上下眼睑。本轮改为共享眼裂边界的组织表面，区分鼻侧和颞侧结构。内眼角有浅的泪阜隆起、半月皱襞形状和局部红润；外眼角以皮肤色连接上下睑。闭合时这些面随眼裂收拢，并在完全闭眼时隐藏，避免留下孤立物体。

## 几何与遮挡

眼裂半宽仍为 13.2 mm。设眼角面横向参数为 u∈[0,1]、上下睑之间的参数为 v∈[0,1]，其内边缘为：

```
a(v) = halfWidth − width × (1 − 0.18 sin(πv))
x = side × ((1−u) a(v) + u × halfWidth)
y = (1−v) lower(x) + v × upper(x)
```

鼻侧宽度为 2.8 mm，颞侧为 1.5 mm；z 由上下睑深度插值，再叠加局部浅隆起和折痕。这些是本轮视觉设计值，**没有声称来自真人参数拟合**。该参数化使眼角始终在上下睑之间，左右眼可镜像，并在闭眼时收拢到同一条闭合线。瞳孔可见比例采用相同内边缘函数排除眼角遮挡，避免新增组织已经遮住瞳孔、数值却仍将该采样点算作可见。

## 材质和连接

- 一次性固定种子生成 1024² 颜色、凹凸和粗糙度纹理。共享 40 mm 纹理坐标使眼周和脸部衔接；不会每帧重新随机毛孔。
- 多尺度色素变化、柔和毛孔凹陷及短而分叉的细纹，替代原先接近均匀的皮肤表面。控制幅度以避免明显的云斑。
- 上睑浅折痕随闭眼放松，下睑保持较柔和的过渡。眼角局部色泽、眼周色调和材质反光分开处理。
- 眼白和虹膜使用眼窝坐标中的解析接触阴影，避免阴影跟着眼球一起转。这里是实时着色近似，不是物理泪膜、真实散射或光学追迹。
- 细长曲线网格逐渐收尖，替代等像素宽的睫毛线段；眉毛在多个高度交错分布。
- 眼周外沿扩大重叠并处理深度冲突，去掉边缘零碎黑点。闭眼时湿润睑缘的高光收弱并隐藏，避免出现白色缝线。

## 验证

28 项 Node 测试通过，包含新眼角的镜像、边界连接、眼裂内约束、闭合和遮挡检查。原项目 3,600 个基准样本的眼动角度仍逐项相同。浏览器检查覆盖首页、三病例演示、工作台、输入/回放/导出和手机布局；另外目视检查了正视、左右、上下、闭眼，以及放大正面和斜视眼角。

导出眼睑版本更新为 `anatomical-lids-v3`，容器仍为 `oculid-run-v1`。眼动模型、病例参数和食指映射未改变。

这轮没有新增真人扫描、眼睑运动捕捉或临床验证。现阶段仍是程序化研究模型；改善的是可检查的连接、纹理和着色，不能据此宣称摄影级真实或医学准确。
