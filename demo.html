How do these cases remain pronounced and stable?

All three use fixed residual capacity c = 0.12, giving an angle-equivalent drive capacity C = 45c = 5.4°. The same normal model supplies the reference and the same continuous response equation modifies it. Only the affected eye and direction differ. Symptoms do not change randomly, and there is no additional saccade examination.

The automatic target moves slowly to about 27° on either side and holds briefly. Gaze in the limited direction approaches 5.4° through a continuous response, rather than frame-by-frame angle clipping. Vertical motion retains the reference output; fingertip input can move freely.

The directional patterns are informed by clinical eye-movement descriptions. Capacity, response timing and the drive equation are engineering approximations. Adduction limitation alone is not a complete INO model. No NIHSS scores are assigned.
