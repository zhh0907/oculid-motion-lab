Camera & screen calibration

Optional intrinsic calibration

Run in the extracted package folder. Save raw checkerboard images in a captures folder. Replace 25 with your measured square size in mm.

python -m pip install -r requirements-calibration.txt
python calibrate_camera.py --images captures --cols 9 --rows 6 --square-mm 25 --output camera-intrinsics.json

Beginner: eight-position setup

Enter the lit display dimensions, select one of the eight positions, enter the distance from the display edge to the lens, then Apply & save position. For a 300 mm tall display with a top camera 10 mm beyond the edge, X = 0 and Y = 160 mm. At a corner, measure diagonally outward at 45°. Only X / Y change; Z, orientation and intrinsics remain as entered. Bind the device and enable calibration afterwards. This shortcut is approximate manual placement, not automatic calibration or depth sensing.

Setup on another computer

  1. Fix the display, webcam and lens settings. Measure the lit display width and height in millimeters.
  2. Use the screen center as the origin: X to the viewer’s right, Y up, Z toward the viewer. Measure the lens center and orientation. Zero angles mean a camera facing the viewer without tilt. Rotations apply roll, then pitch, then yaw. Manual alignment is not an estimated extrinsic calibration.
  3. For measured intrinsics, print the checkerboard (9 × 6 inner corners), measure its actual square size, and capture at least 10 diverse views using “Save raw camera frame”. Do not use mirrored screenshots. Run the commands above with your image folder and square size, then import the JSON.
  4. Check reprojection errors and independent views. This tool estimates intrinsics and distortion; it does not determine camera-to-screen pose.
  5. Set the assumed fingertip distance from the screen. Start and bind the camera, verify capture resolution, save and enable the profile. Enter fullscreen eyes to establish a physical display coordinate frame. The eye separation is 64 mm. Use ideal geometric gaze for checking directions.
  6. Export a backup. On a different setup, remeasure, recalibrate and rebind. A portable file format does not make physical calibration portable between devices.

All processing is local. Browser storage is origin-specific; export before changing host or port. Calibrated tracking pauses on device, resolution, aspect or fullscreen mismatch. RGB depth remains assumed. Physical robot calibration requires a separate workflow.

Physical calibration requires element fullscreen. On unsupported mobile browsers, use ordinary uncalibrated simulation. Remeasure after device rotation, lens, zoom or resolution changes.
