Camera & fingertip position

Allow camera access when prompted and show one hand. Detection runs locally; video is not uploaded.

1.00 m

Projects the detected fingertip onto a plane at this distance from the camera. RGB does not measure absolute depth here; this assumption affects vergence.

60°

The camera’s vertical viewing angle, used to convert image positions to gaze directions. Start with 60° if unknown; accurate control requires calibration.

60 ms

Higher values reduce jitter but add lag. Set to 0 to disable this smoothing. This is separate from the eye model’s own delay.

Human gaze replay

PUR: smooth pursuit; RAN: target jumps / saccades; VRG: depth changes / vergence. Select a recording, then compare controllers on the same target.

Virtual target trajectory

These coordinates set the trajectory’s center, or the ball’s position for a stationary target.

Camera placement

0.30 m

Simulates the height offset between the chest camera and eyes. In camera mode, it affects the coordinate transform; in other modes, it only changes the virtual camera view. This is not a physical robot calibration.
